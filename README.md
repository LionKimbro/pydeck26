# PyDeck 26

PyDeck 26 is a persistent cockpit for entering, understanding, and working within Lion's `python-2026-03` project habitats.

The first runnable slice remembers one selected project folder and maps its Zoo identity, packaging identity, conventional locations, and chronological `docs/raw/` project memory.

## Run

Install the project in an environment where `lionscliapp` is available, then run:

```text
pydeck26
```

The cockpit stores its local selection in a `.pydeck26/` folder beside its execution root. It inspects projects; it does not modify a selected project.
