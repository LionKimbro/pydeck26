# PyDeck 26

PyDeck 26 is Lion's project cockpit for entering, understanding, and working within Python projects organized according to his 2026 project structure. It brings together project structure, key folders and packages, conversation history, feature ideas, working notes, and the project's dictionary entry in one persistent interface.

This first source document was supplied as the initial application brief. The referenced reading list remains with the originating request; its required sources were read before the first implementation began.
